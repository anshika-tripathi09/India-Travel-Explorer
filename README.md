# 🧭 India Travel Explorer

A smart, interactive Python web application built with Streamlit that provides budget-conscious travel recommendations across Indian destinations based on user preferences.

🚀 **Live Demo:** [https://india-travel-app.streamlit.app](https://india-travel-app.streamlit.app)

---

## ✨ Features
- **Dynamic Preference Filtering:** Filter recommendations by budget, travel duration, destination type (Mountains, Beaches, Heritage, etc.), and travel companions (Solo, Family, Friends).
- **Smart Accommodation & Food Suggestions:** Handpicked stay recommendations and local food specialities for each destination.
- **Google Maps Integration:** Direct links to interactive route maps for real-time location and navigation.

---

## 🛠️ Tech Stack
- **Language:** Python 3.x
- **Framework:** Streamlit
- **Deployment:** Streamlit Community Cloud
- **Version Control:** Git & GitHub
